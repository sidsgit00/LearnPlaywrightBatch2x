# LearnPlaywrightBatch2x

A comprehensive JavaScript learning project covering fundamentals from basics to operators, control flow, and practice problems.

Last updated: 2026-06-03


## 🎯 Learning Topics

### Chapter 1: Basics
- JavaScript fundamentals
- Commands and syntax
- Identifier naming rules
- Comments

### Chapter 2: Variables & Hoisting
- `var`, `let`, and `const` differences
- Variable scope and function scope
- Hoisting behavior
- Temporal Dead Zone (TDZ)

### Chapter 3: Literals
- String literals
- Number literals and formats
- Data type representations

### Chapter 4: Operators
- Arithmetic operators
- Comparison operators (strict vs loose)
- Logical operators (&&, ||, !)
- Assignment operators (=, +=, -=, etc.)
- Bitwise operators
- Ternary operator
- Type checking with `typeof`
- Increment/decrement operators

### Chapter 5: Control Flow
- If/else statements
- Conditional logic examples

## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sidsgit00/LearnPlaywrightBatch2x.git
   cd LearnPlaywrightBatch2x
   ```

2. **Run any JavaScript file:**
   ```bash
   node Chapter_01_Basics/01_Basics.js
   ```

3. **Run a specific example:**
   ```bash
   node Chapter_04_Operators/23_assignment_operators.js
   ```

4. **Explore loops examples:**
   ```bash
   node Chapter_08_Loops/P7_fizzbuzz.js
   ```

## 📖 Key Concepts to Master

- **Variable Declaration:** Understand the differences between `var`, `let`, and `const`
- **Hoisting:** How JavaScript hoists function and variable declarations
- **Operators:** All types of operators and how they behave
- **Logical Operators:** Short-circuit evaluation and truthy/falsy values
- **Control Flow:** Conditional statements for decision-making
